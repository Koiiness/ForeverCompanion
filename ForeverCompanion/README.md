# Forever Companion

A WoW: Forever addon that suggests the next good thing to do, which gear to chase and why, what to do with your bags, and how to make gold without going broke.

Install, first steps, sending feedback and troubleshooting:
https://github.com/Koiiness/ForeverCompanion#readme

In game: type /fc or click the minimap button. /fc help lists every command.
